Формулы Excel — ABC по выручке

Шаг 1. Сортировка: выделить → «Данные» → «Сортировка» → по «Выручка» → «от Я к А».
Шаг 2. Доля, %: =B2/СУММ($B$2:$B$20)*100
Шаг 3. Накопительная: первая ячейка =C2, ниже =D2+C3
Шаг 4. Группа: =ЕСЛИ(D2<=80;"A";ЕСЛИ(D2<=95;"B";"C"))
№ Наименование Выручка, ₽ Доля, % Накопит. доля, % Группа
A — до 80 % B — 80–95 % C — свыше 95 %

Формулы Excel — ABC по остаткам

Шаг 1. Сортировка: выделить → «Данные» → «Сортировка» → по «Остаток» → «от Я к А».
Шаг 2. Доля, %: =B2/СУММ($B$2:$B$20)*100 (столбец B — остатки)
Шаг 3. Накопительная: первая ячейка =C2, ниже =D2+C3
Шаг 4. Группа: =ЕСЛИ(D2<=80;"A";ЕСЛИ(D2<=95;"B";"C"))
Правило Парето для остатков: A — 80 % денег «заморожено» в этих позициях, B — 15 %, C — 5 %.
№ Наименование Остаток, ₽ Доля, % Накопит. доля, % Группа

🔀 Матрица «Продажи × Остатки»

Сопоставление двух ABC-групп (по выручке и по остаткам) даёт 9 стратегических квадрантов, каждый из которых требует своей политики закупок.

⚠️ A×A — затоваривание лидера
🔴 C×A — мёртвый груз
🟡 B×A — перезаказ
🟡 C×B — сократить закупки
🟢 A×B, A×C, B×B, B×C, C×C — норма
